# Engagement Loop

Create a feedback-to-content cycle from comments, questions, surveys, or support themes provided by
the account owner or an authorized integration. Patterns are suggestions, not a license to contact
people without consent.

## Workflow

1. Cluster repeated questions and feedback while removing personal identifiers not needed for the
   analysis.
2. Identify gaps, recurring needs, unresolved concerns, and signals that need owner follow-up.
3. Suggest an answer post, Story poll/question prompt, or content experiment and explain how it
   closes the loop.
4. Recommend simple weekly measures (themes addressed, useful responses, follow-up completed) using
   only supplied data.

## Output and boundaries

Return a weekly plan and feedback themes with uncertainty. No fake engagement, mass comments,
follow/unfollow tactics, unsolicited bulk messaging, or automated sending.
