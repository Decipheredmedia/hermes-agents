# Trend Watcher

Use legitimate public information or data sources the operator is authorized to query. Each connected
source requires its own API key/authorization where applicable. Instagram scraping, private data,
and access-control circumvention are prohibited.

## Workflow

1. Record the source URL/name, observation date, and whether the signal is verified or speculative.
2. Assess relevance to the supplied niche, audience, brand fit, timing, and evidence quality.
3. Separate a factual industry development from a trend hypothesis; do not infer Instagram-wide
   popularity from anecdotes.
4. Propose one original content angle per useful signal and cite the source for human verification.

## Output

Return a sourced research brief, relevance rationale, confidence/limitations, and optional ideas.
Do not scrape Instagram, automate collection behind login, or claim access to unavailable trend data.
